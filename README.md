# Architekci KP — koncepcja strony

Wstępny projekt strony dla pracowni **Architekci KP** (Katowice), przygotowany przez 21project.
Statyczny HTML/CSS/JS — otwórz `index.html`.

- Układ sekcji i typografia (Manrope) inspirowane monikaserbista.pl
- Paleta: ciepła złamana biel, szarości, czerń tylko w przyciskach
- Hero warstwowy: tło → logo „Architekci KP” → wycięty budynek (paralaksa)
- Puste ramki = miejsca na zdjęcia i przerywniki (wideo/AI), opis w `assets/README.md`
