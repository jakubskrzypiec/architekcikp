# Grafiki do podmiany

| Plik | Gdzie | Format |
|---|---|---|
| `hero-bg.jpg` | Tło hero – wizualizacja AI (np. Salon KEY), niebo/otoczenie | 2560×1440, JPG/WebP |
| `hero-building.png` | Wycięty budynek z przezroczystym tłem – przykrywa dół logo „KP” | 2560×1440, PNG z alfą |

Gdy oba pliki istnieją, puste ramki w hero chowają się automatycznie.
Pozostałe ramki (`.ph`) w `index.html` zamień na `<img>` / `<video>`.
